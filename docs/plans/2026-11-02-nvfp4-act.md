**Tech Stack:** Python 3.10+ stdlib (host), pytest; container: llmcompressor 0.13.0, compressed-tensors 0.18.0; eval: vLLM 0.28.

**Spec:** `docs/specs/2026-10-30-qtool-design.md` (v3.2, §3, §4, §6, §7, §9, §11)
